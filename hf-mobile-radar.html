Оболочки для запуска моделей на телефоне
Жёсткий мобильный фильтр. По умолчанию оставляем только имена с размером 1B · 2B · 3B · 3.8B · 4B · 5B · 7B · 8B · 9B, а также mini / nano (набор размеров меняется в настройках). Всё, где встречается размер больше 9B (14B, 30B, 70B, MoE вроде 26B-A4B), отбрасывается — даже если в названии есть «mini».
Источник: huggingface.co/api/models · авторы: bartowski, mradermacher, city96, google, unsloth · ключевые слова: gguf, litert, abliterated, uncensored.
Кнопка ТОП строит единый рейтинг: влезает ли в бюджет ОЗУ, свежесть, загрузки, лайки, доверие к автору и готовность формата (GGUF/LiteRT) — на карточках видно число рейтинга.
Авторы по умолчанию: bartowski, city96, google, unsloth, TheBloke, cyankiwi, lonestriker — модели чужих авторов отбрасываются (видно в панели «Отсечено»).
«☆» складывает модель в избранное (живёт в localStorage, не теряется, даже когда модель уходит из ленты). Кнопка сортировки ⇅ умеет «Под мой телефон»: наверху то, что реально влезает в бюджет ~5 ГБ, с оценкой веса на карточке (точная, если файлы уже подгружались).
Вкладка «Оболочки» — каталог приложений для запуска моделей на телефоне (Android/iOS), с живыми данными из GitHub API: последний релиз, размер APK и подбор файла под чип (для Snapdragon 8 Elite — sm8750). Данные кэшируются на 6 часов, потому что GitHub без токена даёт 60 запросов в час; свои репозитории добавляются полем owner/repo.
Кнопка «Поделиться» на карточке собирает готовый отчёт (название, автор, размер, метки, ссылка) и отдаёт его в системную шторку «Поделиться» — оттуда Telegram в пару тапов; есть и простое копирование. Метка «НОВОЕ» = модель создана после предыдущего запуска, «ОБНОВЛЕНО» = старая модель, у которой изменились файлы (lastModified). Время хранится в localStorage этого браузера.
Настройки (шестерёнка в шапке): авторы, ключевые слова, разрешённые размеры, слежение за обновлениями, а также экспорт/импорт .json — чтобы не править код и переносить профиль между устройствами.
Тап по карточке открывает страницу модели на Hugging Face.
